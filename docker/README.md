# Mojave Docker

This folder contains Docker assets for the runnable mono applications:

- `mono/core/admin`
- `mono/core/intercom`
- `mono/core/consumer`
- `mono/rail/fspiop`

It also provisions shared infrastructure in Docker Compose:

- MySQL
- NATS with JetStream enabled

## Files

- `compose.yml`: local stack definition
- `mono/core/admin/Dockerfile`: image for `mojave-mono-core-admin`
- `mono/core/intercom/Dockerfile`: image for `mojave-mono-core-intercom`
- `mono/core/consumer/Dockerfile`: image for `mojave-mono-core-consumer`
- `mono/rail/fspiop/Dockerfile`: image for `mojave-mono-rail-fspiop`

## Run

From the repository root:

```bash
docker compose -f docker/compose.yml up --build
```

To stop the stack:

```bash
docker compose -f docker/compose.yml down
```

To stop and remove volumes too:

```bash
docker compose -f docker/compose.yml down -v
```

## Default Ports

- MySQL: `3306`
- NATS: `4222`
- NATS monitoring: `8222`
- Mono Core Admin: `8081`
- Mono Rail FSPIOP: `8080`

## Notes

- The compose file uses one shared MySQL schema: `mv_mojave`.
- The images build from the `modules/` source tree and run the mono applications with the compiled `classes` and `lib/*` layout generated by Maven.
- The FSPIOP values in `compose.yml` are starter defaults for local development and can be adjusted as needed.
